Privacy Policy

WoW Music Uploader - last updated 1 November 2026

What this app is

WoW Music Uploader is a private tool used only by the owner of the YouTube channel Forever Leveling Music. It runs on the owner's own computer and is not offered to the public.

What Google data it uses

With the owner's permission (Google sign-in), the app uses the YouTube Data API and the YouTube Analytics API to:

  • upload the channel's own videos, Shorts and thumbnails;
  • create and fill the channel's own playlists;
  • read the channel's own view and watch-time statistics for a weekly report.

It does not access any other user's account or data.

Storage and sharing

The sign-in token and the statistics are stored only on the owner's computer. No Google user data is sold, shared with third parties, or used for advertising. Summary statistics (numbers only, no personal data) may be sent to an AI service to write the owner's weekly report and to the owner's own Telegram chat.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored access.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: contact the channel via its YouTube About page.
